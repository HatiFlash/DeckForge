# NovyDeck 0.10.1 — cleaner deck header and English fixes

## English

- **Deck header.** The profile name and help line stay inside the rounded deck card with proper margins; a long profile name is shortened with "…" and shown in full in a tooltip. Page navigation is now one grouped control on the right with crisp arrows that highlight on hover and are greyed out when there is only one page. The header gets more compact in low windows so keys stay large.
- **English interface.** The Undo button reads "Undo" instead of "Cancel"; library categories (System, Media…), step names in the key inspector and the Add step menu are translated.

Your profiles, key images, macros and plugins are kept.

## Français

- **En-tête du deck.** Le nom du profil et la phrase d'aide restent dans la carte arrondie du deck avec de vraies marges ; un nom de profil trop long est raccourci avec « … » et affiché en entier dans une infobulle. La navigation entre pages devient un seul contrôle groupé à droite, avec des flèches nettes qui s'éclairent au survol et se grisent quand il n'y a qu'une page. L'en-tête se resserre dans une fenêtre basse pour garder des touches lisibles.
- **Interface anglaise.** Le bouton Annuler affiche « Undo » au lieu de « Cancel » ; les catégories de la bibliothèque (System, Media…), les noms d'étapes dans l'inspecteur et le menu Add des étapes sont traduits.

Vos profils, images de touches, macros et plugins sont conservés.
