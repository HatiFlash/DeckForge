# Essais manuels 0.5.0

À faire avec le D6 branché, FIFINE fermé. Cocher au fur et à mesure.

## Base

- [ ] Les profils, pages, icônes et macros de la 0.4.3 sont présents après le premier lancement (copie de la configuration).
- [ ] L'aperçu et le D6 affichent les mêmes touches ; titres lisibles.
- [ ] Un appui exécute la bonne touche ; navigation pages / dossiers.

## Édition

- [ ] Clic droit sur une touche : Copier, Coller sur une autre page, Dupliquer vers la prochaine touche vide.
- [ ] Ctrl+Z / Ctrl+Y annulent et rétablissent ; le D6 suit.
- [ ] Ouvrir « image + » et laisser la boîte ouverte : les appuis du D6 fonctionnent encore.

## Atelier

- [ ] Partir d'un modèle, le personnaliser en mode Simple, simuler : le déroulé est lisible.
- [ ] Désactiver un bloc : il est grisé et sauté à l'exécution.

## Appui long

- [ ] Touche sans appui long : réaction immédiate.
- [ ] Touche avec appui long : appui bref = action courte, maintien 0,5 s = action longue, une seule fois.

## Icônes animées

- [ ] GIF sur une touche : animation dans l'aperçu et sur le D6, sans ralentir les appuis.
- [ ] Si le D6 n'anime pas ou se fige : relancer avec la variable `DECKFORGE_D6_FRAME_ULEND=1`.
- [ ] Importer une courte vidéo : conversion puis animation.
- [ ] Curseur Taille de l'icône : effet identique aperçu / D6.

## Profils et veille

- [ ] Associer un exécutable à un profil, activer le changement automatique, passer sur cette application puis revenir.
- [ ] Veille à 1 minute : l'écran baisse ; le premier appui réveille sans lancer la macro.
