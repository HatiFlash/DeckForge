# NovyDeck 0.9.3 — security badges, cleaner plugins, quieter updates

## English

- **Security badges in the plugin store.** Every plugin in the catalogue is now scanned automatically on GitHub (Microsoft Defender plus a static check of the archive) when it is added or updated, and again every week. Cards and plugin pages show **Official** (published by NovyDeck), **Scanned** (the exact archive passed the scan) and **Tested by NovyDeck** (that exact version was tried by hand). A plugin whose scan needs review shows a warning, and the install confirmation highlights it. A scan reduces risk; it cannot rule it out completely.
- **Official plugins 1.0.2.** Each of the seven NovyDeck plugins has its own logo, and their settings pages were redesigned: one language at a time (French or English, following NovyDeck), grouped cards, clear help text and number checks. The System Monitor reads the CPU temperature when Windows exposes it and shows "N/A" instead of a misleading value when a sensor is unavailable. Update them from the plugin store.
- **Quieter updates.** Updating from inside NovyDeck no longer opens a black console window. Note: the update from 0.9.2 to 0.9.3 is still started by 0.9.2, so the console may appear one last time.
- **Plugin settings window.** It is smaller, titled with the plugin and action names, attached to the NovyDeck window, and the plugin receives your interface language.
- **Polish.** Secondary windows (Settings, About, AI assistant…) stay centered and can no longer be dragged around. ON/OFF keys keep their state when you switch pages during the session (they start OFF again after a restart). Remaining French texts in the English interface were translated, and plugin keys show readable plugin and action names.

Your profiles, macros, media and plugins are kept.

## Français

- **Badges de sécurité dans le magasin de plugins.** Chaque plugin du catalogue est désormais analysé automatiquement sur GitHub (Microsoft Defender et contrôle de l'archive) à son ajout, à chaque mise à jour, puis chaque semaine. Les cartes et les fiches affichent **Officiel** (publié par NovyDeck), **Analysé** (l'archive exacte a passé l'analyse) et **Testé par NovyDeck** (cette version précise a été essayée à la main). Un plugin dont l'analyse est à examiner affiche un avertissement, repris dans la confirmation d'installation. Une analyse réduit les risques sans les supprimer.
- **Plugins officiels 1.0.2.** Les sept plugins NovyDeck ont chacun leur logo, et leurs pages de réglages ont été refaites : une seule langue à la fois (français ou anglais, comme NovyDeck), cartes groupées, aides claires et contrôle des nombres. Le moniteur système lit la température du processeur quand Windows la fournit et affiche « N/D » plutôt qu'une valeur trompeuse quand un capteur manque. Mettez-les à jour depuis le magasin.
- **Mises à jour plus discrètes.** La mise à jour depuis NovyDeck n'ouvre plus de fenêtre de console noire. Attention : le passage de 0.9.2 à 0.9.3 est encore lancé par la 0.9.2, la console peut donc apparaître une dernière fois.
- **Fenêtre de réglages des plugins.** Plus compacte, titrée avec le nom du plugin et de l'action, rattachée à la fenêtre NovyDeck ; le plugin reçoit la langue de l'interface.
- **Finitions.** Les fenêtres secondaires (Réglages, À propos, Assistant IA…) restent centrées et ne se déplacent plus. Les touches ON/OFF gardent leur état quand on change de page pendant la session (elles repartent sur OFF au redémarrage). Les textes encore en français dans l'interface anglaise sont traduits, et les touches de plugins affichent des noms lisibles.

Vos profils, macros, médias et plugins sont conservés.
