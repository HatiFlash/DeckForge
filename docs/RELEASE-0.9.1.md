# NovyDeck 0.9.1 — integrated plugin store

English · [Français](#français)

## English
- **The plugin store is now a page of the app.** It opens in the main area like the block editor, keeps the top bar visible and can no longer be moved or overflow the window. Use **← Back to deck** (or **← Back** on a plugin page) or press **Esc**. Install confirmations and enlarged screenshots stay centered.
- **Readable plugin blocks.** In the block editor, plugin blocks show the plugin and action names (for example “NovyDeck Clock › Stopwatch”) instead of technical identifiers.
- **README:** new “What's new in 0.9.0” section with screenshots of the plugin store, plugin actions in the block editor and the start-minimized option.

Your profiles, media and plugins are kept. Update with **About → Check for updates** or the installer.

## Français
- **Le magasin de plugins devient une page de l'application.** Il s'ouvre dans la zone principale comme l'Atelier de blocs, garde la barre du haut visible et ne peut plus être déplacé ni dépasser de la fenêtre. Utilisez **← Retour au deck** (ou **← Retour** sur la fiche d'un plugin) ou la touche **Échap**. La confirmation d'installation et l'agrandissement des captures restent centrés.
- **Blocs de plugins lisibles.** Dans l'Atelier, les blocs de plugins affichent les noms du plugin et de l'action (par exemple « NovyDeck Clock › Stopwatch ») au lieu des identifiants techniques.
- **README :** nouvelle section « Nouveautés 0.9.0 » avec captures du magasin, des actions de plugins dans l'Atelier et de l'option de démarrage réduit.

Vos profils, médias et plugins sont conservés. Mise à jour par **À propos → Vérifier les mises à jour** ou l'installateur.
