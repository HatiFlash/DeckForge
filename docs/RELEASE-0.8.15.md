# NovyDeck 0.8.15 — languages and smarter updates

English · [Français](#français)

## English
- **English interface.** Choose the language in **Settings → Language**; on first start NovyDeck follows the Windows language. Every language is a JSON file in `res/i18n/`, so the community can add one with a pull request ([translation guide](https://github.com/HatiFlash/NovyDeck/blob/main/docs/TRANSLATING.md)).
- **Update check at startup.** NovyDeck asks once whether it may check GitHub for a new version when it starts. You can change this choice in **Settings**. Nothing is installed without your confirmation.
- **Release notes before installing.** When a new version is available, its description is shown before you click **Download and install**.
- **What's new.** After an update, a window summarizes the new version once.
- README: plugin store and community library explained, with how to submit a plugin.

Your profiles, media and plugins are kept. Updating from 0.8.14: use the installer or **About → Check for updates**.

## Français
- **Interface en anglais.** Choisissez la langue dans **Réglages → Langue** ; au premier démarrage, NovyDeck suit la langue de Windows. Chaque langue est un fichier JSON dans `res/i18n/` : la communauté peut en ajouter une par pull request ([guide de traduction](https://github.com/HatiFlash/NovyDeck/blob/main/docs/TRANSLATING.md)).
- **Vérification des mises à jour au démarrage.** NovyDeck demande une fois s'il peut vérifier sur GitHub qu'une nouvelle version existe au lancement. Ce choix se modifie dans les **Réglages**. Rien n'est installé sans votre confirmation.
- **Nouveautés avant l'installation.** Quand une version est disponible, sa description s'affiche avant le bouton **Télécharger et installer**.
- **Quoi de neuf.** Après une mise à jour, une fenêtre résume une fois la nouvelle version.
- README : présentation du magasin de plugins et de la bibliothèque communautaire, et comment proposer un plugin.

Vos profils, médias et plugins sont conservés. Depuis la 0.8.14 : installateur ou **À propos → Vérifier les mises à jour**.
